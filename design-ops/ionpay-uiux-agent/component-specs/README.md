# ionPAY Component Specs

This folder defines reusable UI component specifications for the ionPAY UI/UX Execution Agent.

These specs are design-only until routed for implementation.

## Component families

1. App shell.
2. Balance card.
3. Action grid.
4. Payment confirmation panel.
5. QR display panel.
6. Receipt card.
7. Proof row.
8. Activity row.
9. Merchant summary card.
10. Security state card.
11. Empty state.
12. Error state.
13. Pending state.
14. Terminal / ASCII proof panel.

## Rule

Component specs guide implementation but do not authorize app code changes by themselves.
